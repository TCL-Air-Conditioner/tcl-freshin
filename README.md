# TCL FreshIN 视频网页（预览）

本仓库按 12 个主题生成手机友好的静态页面。缺少原视频时，该主题显示 “Video coming soon.”；仓库最初没有包含任何 MP4，因此当前页面仅供版式和目录预览。

## 添加原视频与生成页面

1. 将每个原始 MP4 放进同名主题文件夹，例如 `fresh-air-function/fresh-air-function.mp4`。文件名和大小写必须与目录一致；不需要上传单独的封面。
2. 在安装 Python 3 和 FFmpeg 的环境中运行 `python3 build_pages.py --in-place`。脚本从已有视频提取封面、计算内容版本，并更新所有页面及缓存配置；缺失的视频继续显示待提供。脚本只读取原视频，不会压缩、覆盖或修改原视频。
3. 一起提交视频、生成的页面、`covers/`、`index.html` 和 `sw.js`。视频有变化时需要重新运行。浏览器缓存由设备和网络条件决定，首次播放仍需下载视频。

视频文件超过 GitHub 单文件限制时，需要另行选择合适的托管方式；不要将 Git LFS 指针当作可直接播放的 MP4。

参考实现：TCL 360° Round Cassette 的 `54c1aa9241e32043afa91e62d2630114f1d9fc25`。请在发布后用真实手机与微信环境验证画面及播放。
